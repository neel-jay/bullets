✦ YouTube Summarizer

Right-click any YouTube thumbnail or video → Summarize video → AI picks best format via DeepSeek or your local AI. Works without opening the video.

Get key at platform.deepseek.com/api_keys. Stored locally via chrome.storage.sync, never sent anywhere except api.deepseek.com. Not needed if you use Local AI below.
Local runs on your machine — private, offline, no API key. Requires a local OpenAI-compatible server.
Ollama default: http://localhost:11434/v1 (LM Studio: http://localhost:1234/v1). Recommended models: qwen2.5:14b, llama3.1:8b. Set big context before use: ollama run <model> → /set parameter num_ctx 32768 → /save. First summary after starting server may take a while (model load).
Auto: short video → TL;DR + bullets, tutorial → steps + ASCII flowchart A --> B --> C, deep dive → headers + diagram. Uses TITLE + DURATION to choose.
Full processes whole transcript in parallel chunks, streams first page after ~30s, paginates. Fast truncates to 50k chars and single AI call — good for quick preview of long videos. Cached results make both instant on repeat.

Folder inside vault for new clips. Default: Clips. Created automatically via obsidian://new. Button also downloads .md as fallback if URI too long or vault not set.

How to use (no need to open)

  1. Save DeepSeek API key above or switch provider to Local (Ollama/LM Studio) and pick style
  2. On any youtube.com page (home, search, watch), right-click a video thumbnail/link → Summarize video
  3. Or on watch page: right-click video/page → Summarize video
  4. Modal appears on current page with AI-chosen format (bullets, steps, or ASCII diagram tuned to title & duration). Copy if needed.

Troubleshooting

  1. No captions → video has captions disabled, try another video
  2. 401 error → API key invalid / expired
  3. Local AI fails → server not running (start Ollama: ollama serve) or wrong endpoint/model
  4. No context menu → reload YouTube tab after installing extension
